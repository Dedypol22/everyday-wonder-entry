# A Door in the Fog

[![make.fun](https://make.fun/badge/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)](https://make.fun/competitions/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)

> "The bus window fogs with my breath, and my fingertip draws a door in it that opens onto nothing but more rain."

## Why this moment works

Everyone who has ridden a bus in the rain knows the fogged window and the idle fingertip — the moment is small, real, and instantly recognisable. The wonder arrives in the last four words: the door, drawn as a way out, opens onto nothing but *more* rain. The escape leads nowhere new, only deeper into the weather already outside. Nothing in the sentence is invented or exotic; the strangeness is made entirely out of breath, glass, and rain, and it lands in a single read.

## Run it

```sh
python3 main.py
```

This writes the sentence to `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.
